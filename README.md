- `README.md` — Diese Datei

## GitHub Pages aktivieren (falls noch nicht geschehen)

1. Gehe auf **GitHub** → dein Repo `kf-builds/kf-builds.github.io`
2. Klicke auf **Settings** (reiter)
3. Scrolle zu **Pages** (links im Menü)
4. Bei **Source** wähle **Deploy from a branch**
5. Wähle bei **Branch** den `main`-Branch und den Ordner `/ (root)`
6. Klicke auf **Save**
7. Warte 1–2 Minuten, dann ist die Seite unter `https://kf-builds.github.io` erreichbar

## Lokal testen

Einfach die `index.html` im Browser öffnen. Keine Server nötig.
